
# 🎓 3D Academi — Ambiente Virtual para Lições de Montagem

## 📖 Sobre o projeto

O **3D Academi** é uma plataforma educacional web que tem como objetivo proporcionar aprendizagem prática por meio de simulações tridimensionais interativas e elementos de gamificação.

O projeto busca facilitar o acesso ao conhecimento técnico, permitindo que estudantes pratiquem procedimentos relacionados à montagem, desmontagem e identificação de problemas em equipamentos de informática, sem a necessidade de utilizar componentes físicos.

A proposta é oferecer um ambiente virtual acessível, interativo e educativo, no qual o usuário possa desenvolver habilidades técnicas de maneira segura.

## 🎯 Objetivos

- Proporcionar experiências práticas de aprendizagem em informática.
- Simular a montagem e desmontagem de computadores.
- Apresentar modelos tridimensionais de gabinetes e componentes.
- Permitir a identificação e resolução de problemas de hardware.
- Desenvolver atividades interativas com avaliação de desempenho.
- Utilizar gamificação para tornar o aprendizado mais dinâmico.

## 🖥️ Módulo de simulação 3D

Uma das funcionalidades em desenvolvimento é o ambiente de visualização tridimensional de equipamentos de informática.

O primeiro modelo desenvolvido é um gabinete gamer com estrutura panorâmica, vidro temperado e componentes internos representados em ambiente 3D.

### Funcionalidades do modelo 3D

- Visualização tridimensional do gabinete.
- Rotação de 360° utilizando o mouse.
- Aproximação e afastamento por zoom.
- Visualização frontal, lateral e traseira.
- Representação da estrutura externa e interna.
- Modelagem de ventoinhas, placa-mãe e placa de vídeo.

Os modelos são construídos programaticamente utilizando geometria tridimensional, materiais e iluminação.

## 🚀 Como executar o projeto

### Pré-requisitos

- Visual Studio Code.
- Navegador atualizado.
- Extensão Live Server.
- Conexão com a internet para carregar a biblioteca Three.js via CDN.

### Instalação e execução

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Abra a pasta do projeto no Visual Studio Code.

3. Localize o arquivo `index.html`.

4. Clique com o botão direito no arquivo.

5. Selecione **Open with Live Server**.

6. O navegador abrirá a aplicação.

## 📚 Finalidade educacional

O 3D Academi busca complementar o ensino teórico por meio de experiências práticas simuladas.

A utilização de modelos tridimensionais permite que o estudante explore equipamentos, conheça seus componentes e compreenda procedimentos técnicos sem o risco de danificar peças físicas.

O projeto também prevê a expansão futura para outras áreas do conhecimento, como odontologia e mecânica.
